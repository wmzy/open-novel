2. **RunStream 落盘失败静默丢事件**
   - 位置：`src/agent/run-stream.ts` `doFlush()` 失败仅 console.error，pending 已清空事件永久丢失；`close()` 固化消息失败被吞。
   - 方案：flush 失败将缓冲放回队列并重试一次；两次失败给 run 打错误标记。

## P1 — 真实缺陷

3. **useRun 渲染体内可变变量（多闭包副本）**
   - 位置：`src/web/hooks/useRun.ts:350-353`，`pendingTextDelta`/`rafId` 为渲染体 `let`，conversation 流 effect 与 sendMessage SSE 循环各捕获不同渲染副本，交错时 delta 可能丢失。
   - 方案：改为 `useRef` 统一持有。

4. **useRun 返回 ref 派生值，UI 依赖巧合时序**
   - 位置：`useRun.ts:614-617`，`activeRunCount`/`conversationId` 读 ref 不触发重渲染；ChatPanel `(N active)` 徽标在并行 run 场景显示过期值。
   - 方案：activeRunCount 改真实 state；conversationId 由 ChatPanel 在 sendMessage 返回时自行管理。

5. **maxBodySize 可被 chunked 绕过**
   - 位置：`src/api/middleware/security.ts`，只查 content-length。方案：换 Hono 内置 `bodyLimit`。

6. **文件事件 SSE 断开后无重连**
   - 位置：`src/web/hooks/useProjectFiles.ts`，`onerror` 后 close 无重连，事件静默消失。方案：指数退避重连 + 卸载标志。
